# Интерактивный UI дашборд

## Запуск веб-панели
Запуск выполняется одной командой:
```bash
ibm-bell-web
```
или через Python:
```bash
python -m web.app
```
Веб-сервер запускается на `http://127.0.0.1:8000`.

## Возможности интерфейса
- **Интерактивные параметры sweep**:
  - Настройка числа выстрелов (*Shots*): от 64 до 10 000.
  - Настройка сетки углов измерений Алисы и Боба $\theta_A$ и $\theta_B$ от 0 до $\pi/2$.
  - Выбор бэкенда: авто-выбор наименее загруженного реального процессора (Least Busy QP) или явный симулятор.
- **Интерактивный симулятор прогресса и логи в реальном времени**:
  - Отображение текущего квантового статуса и очереди задач в терминале дашборда.
- **Визуализация результатов**:
  - **Матрица корреляций**: тепловая цветовая схема (от синего -1.0 до изумрудно-зеленого +1.0).
  - **Интерактивный график Chart.js**: кривые корреляций при разных срезах углов.
- **История запусков**:
  - Все прогоны сохраняются на диск с меткой времени.
  - Нажав на любой исторический запуск в левом списке, можно мгновенно восстановить его данные и график.
