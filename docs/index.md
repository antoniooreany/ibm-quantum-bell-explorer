# IBM Quantum Bell Explorer

Добро пожаловать в документацию **IBM Quantum Bell Explorer** — модульной платформы для демонстрации квантовой запутанности и экспериментальной проверки нарушения неравенства Белла (CHSH) на реальных квантовых компьютерах IBM Quantum и квантовых симуляторах.

## Главные возможности
- **Hardware-First подход**: эксперимент в первую очередь стремится запуститься на наименее загруженном реальном квантовом процессоре IBM Quantum, и лишь в случае недоступности переключается на симулятор.
- **Интерактивный веб-дашборд**: визуальная панель на базе FastAPI + HTML5/CSS3 + Chart.js с динамической матрицей корреляций, графиками и историей запусков.
- **Хранение результатов с таймстемпом**: все запуски логируются с уникальной временной меткой в формате `grid_YYYYMMDD_HHMMSS.csv`.
- **Безопасное хранение токенов**: поддержка системного хранилища (через `keyring`), Google Colab Secrets и переменных окружения (`IBM_QUANTUM_TOKEN`).
- **Соблюдение лучших инженерных практик**: разработка по SDD, TDD, строгий Gitflow и непрерывная интеграция CI/CD через GitHub Actions.

## Быстрый старт
Для запуска интерактивного веб-интерфейса выполните:
```bash
ibm-bell-web
```
Интерфейс откроется по адресу `http://localhost:8000`.
